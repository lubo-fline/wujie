城市飞线 / 流动线 FLOW LINES

节点之间用二次贝塞尔画弧线，一颗亮点沿曲线跑并拖尾。对应「流动线」「卫星通信过境」「动态缓冲区」「路径漫游」那类效果。关键是用参数 t 在贝塞尔上取点，线本身只是背景。

FLOW · BEZIER
—
// 二次贝塞尔：P0 起点，P1 控制点（抬高 = 弧线），P2 终点
function bez(p0,p1,p2,t){
  const u = 1-t;
  return { x: u*u*p0.x + 2*u*t*p1.x + t*t*p2.x,
           y: u*u*p0.y + 2*u*t*p1.y + t*t*p2.y };
}
const head = bez(a, ctrl, b, t);  // 亮点位置，拖尾取 t-δ 的几个点

这些效果在 Cesium 里怎么落 MAPPING

· 雷达/扫描 → 旋转的 Geometry + 半透明 Material，或 Entity 每帧改属性。
· 飞线 → PolylineGlowMaterialProperty + 沿线运动的点，或用 CallbackProperty 动态算位置。
· 建筑泛光 → 3D Tiles 的 CustomShader 按高度/属性染色，或 Entity 拉伸体 + 发光材质。
· 粒子 → ParticleSystem，配 Burst 发射器与 Color/Size 生命周期。
· 风场/热力 → 贴图图层（SingleTileImageryProvider）或自定义 Primitive。
