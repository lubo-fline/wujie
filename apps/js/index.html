01 CSS Custom Highlight API · 不插一个标签的高亮

传统做法要把关键词包进 <mark>，改一个词就得动 DOM。Highlight API 反过来：用 Range 圈出范围、注册成 Highlight，样式写在 ::highlight(name) 里——文字还是原文，DOM 一个节点都不加。点按钮试试圈中不同的范围。

浏览器的渲染管线把样式计算、布局、绘制分层处理，而 CSS 动画只在合成阶段工作。理解关键帧如何被插入渲染管线，你就明白为什么有些动画流畅、有些会卡：凡是能跳过布局与绘制、只留在合成层的动画，都是浏览器最喜欢的。

const range = new Range(); range.setStart(textEl.firstChild, 5); // 起点字符 range.setEnd(textEl.firstChild, 10); // 终点字符 const hl = new Highlight(range); CSS.highlights.set('kw', hl); // 注册 /* CSS 侧：样式给「命名高亮」，不给元素 */ ::highlight(kw) { background: rgba(255,212,121,.14); }

02 @property · 让 CSS 变量从字符串变成数字

点下面任一色块：左边没注册 @property，浏览器把 --pa 当字符串，transition 无法插值，角度瞬跳；右边注册成了 <angle> 类型，同一个 transition 平滑转动。一个声明，决定变量能不能被"动画"。

未注册 · 瞬跳
--pa 只是字符串，transition 摆烂
已注册 · 平滑转
syntax: '<angle>'，浏览器会插值
@property --pa { syntax: ''; /* 告诉浏览器这是角度 */ initial-value: 0deg; inherits: false; } .box { transition: --pa .5s; } /* 现在能过渡了 */ box.style.setProperty('--pa', '180deg');

03 View Transitions API · 状态切换自带补间

04 60 行的迷你动画库 · 链式调用

动画库的核心只是一个循环 + 一组缓动函数 + Promise 链。下面这个小库支持 .to(props, opts).to(...).then(...) 链式书写和三种缓动。点按钮看它跑，控制台里能看到序列日志。

// 点「跑一段序列」看日志
function tween(el, props, { dur = 600, ease = easeOutCubic } = {}) { const from = readStyles(el, props); return new Promise((res) => { const t0 = performance.now(); (function frame(now) { const p = Math.min(1, (now - t0) / dur); for (const k in props) { el.style[k] = from[k] + (props[k] - from[k]) * ease(p) + unit(k); } p < 1 ? requestAnimationFrame(frame) : res(el); })(t0); }); } /* 用起来就是链 */ tween(box, { left: 340 }) .then(() => tween(box, { top: 10, borderRadius: '50%' })) .then(() => tween(box, { left: 16, top: 50 }));
