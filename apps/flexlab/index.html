1rem 是怎么来的 DESIGN → CSS

lib-flexible 把 html 的 font-size 设为「屏幕宽度 ÷ 10」，所以 1rem = 根节点 font-size。设计稿宽 750px 时，1rem = 75px；量到 150px 的元素，CSS 就写 width: 2rem。下面换个设计稿宽度、拖一下测量值，实时看换算。

为什么大屏会「缩水」 THE 540 CAP

      
lib-flexible 默认面向移动端：源码里把计算基准宽度钳制在 540px（width > 540 ? 540 : width），且 dpr 默认为 1。这意味着在 1920 大屏上，它仍按 540 算 —— 1rem = 54px，一个 width: 10rem 的元素只有 540px，占不满屏。这是它不适合直接做大屏的根因。

源码关键行（node_modules/lib-flexible/flexible.js）：

      
// 原生：写死上限与 dpr
var setRemUnit = function () {
  var width = docEl.clientWidth
  if (width > 540) { width = 540 }   // ← 大屏被钳制
  docEl.style.fontSize = width / 10 + 'px'
}
var dpr = window.devicePixelRatio || 1  // ← 大屏 dpr 常非 1

      
注意：直接改 node_modules 里的源码不持久（npm install 会覆盖）。更稳的做法：fork 一份自己维护、用 amfe-flexible、或自己写 setRem / 直接用 vw 方案。

    

  


  
  

    

      

        
vue-cli 2.x px2rem-loader 生效

        
在 build/utils.js 的 exports.cssLoaders 里生成 loader，再挂到 generateLoaders 的 loaders 数组；重启 npm run dev。

        
// build/utils.js
var px2remLoader = {
  loader: 'px2rem-loader',
  options: { remUnit: 75 }  // 设计稿750 → 1rem=75px
}
function generateLoaders(loader) {
  var loaders = [cssLoader, px2remLoader]
  return loaders.concat([loader])
}
// 安装
npm i lib-flexible px2rem-loader -D
// main.js
import 'lib-flexible'

      

      

        
vue-cli 3.x postcss-pxtorem 3.x 改用

        
3.x 下 px2rem-loader 未生效，改用 postcss 插件，效果一致。在 vue.config.js 配 css.loaderOptions.postcss，重启即可。

        
// vue.config.js
module.exports = {
  css: {
    loaderOptions: {
      postcss: {
        plugins: [
          require('postcss-pxtorem')({
            rootValue: 75,
            propList: ['*'],
            exclude: /node_modules/i
          })
        ]
      }
    }
  }
}
// 安装
npm i postcss-pxtorem -D

      

    

    
温馨提示：postcss-pxtorem 对行内样式（style="width:150px"）无效 —— 它只处理打包时的 CSS 文件。行内样式、运行时动态写入的 px 需要用 JS 兜底（见下一页 calculationRem）。另外 rootValue 要和设计稿基准对应（750 稿填 75，375 稿填 37.5）。

  


  
  

    

      
行内样式的兜底 JS 实时算 px

      
对 px2rem / postcss 管不到的行内样式，直接按当前页面宽度算 px 再渲染。原方案以 1920 为基准：parseInt((px / 1920) * clientWidth)。下面把函数原样实现，输入设计稿 px 和页面宽度，即时看输出。

易错点：parseInt 会向下取整丢精度，需要小数时改用 parseFloat 或 Math.round；基准宽（1920）必须和设计稿标注时的宽度一致，否则整体比例会偏。这个函数返回的是 px，直接赋给行内样式即可，不要再乘 rem。
